## Mitä opit

- Löydät kurssilla käytettyjen alustan, tietosuojan ja migraation keskeiset termit.

| Termi | Merkitys |
| --- | --- |
| Rekisterinpitäjä | Taho, joka määrittää henkilötietojen käsittelyn tarkoitukset ja keinot. |
| Datan alueellinen sijainti | Sitoumus alueesta, jolla soveltuvia tietoja tallennetaan tai käsitellään. |
| DPA | Tietojenkäsittelysopimus, jossa määritellään henkilötietojen käsittelijää ja siihen liittyvää tietosuojaa koskevat ehdot. |
| DPIA | Tietosuojaa koskeva vaikutustenarviointi, jota käytetään korkean riskin käsittelyn arviointiin tarvittaessa. |
| EMU | Enterprise Managed User, organisaation identiteetintarjoajan kautta luotu ja hallittu tili. |
| GEI | GitHub Enterprise Importer, migraatiotyökalu; tuetut lähteet ja siirrettävät tiedot vaihtelevat. |
| GHE.com | GitHub Enterprise Cloud with data residency, joka käyttää yrityskohtaista alitoimialuetta ja valittua aluetta. |
| IdP | Identiteetintarjoaja, jota käytetään hallittujen tilien tunnistamiseen ja provisiointiin. |
| Henkilötietojen käsittelijä | Taho, joka käsittelee henkilötietoja rekisterinpitäjän puolesta. |
| SCIM | System for Cross-domain Identity Management, jota käytetään tässä hallittujen käyttäjien provisiointiin. |
| SCCs | Vakiosopimuslausekkeet, sopimusmekanismi vaatimukset täyttäville kansainvälisille tiedonsiirroille. |
| TIA | Tiedonsiirron vaikutustenarviointi, jossa arvioidaan siirtoon liittyviä riskejä ja suojatoimia. |
