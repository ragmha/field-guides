## What you will learn

Governance begins with a complete list of what can start agent work. Copilot automations run on schedules, repository events or API calls. Agent work can also start from scripts that call the agent tasks or issue assignment APIs, and from GitHub Actions workflows that run Copilot CLI. Each route has a different trigger, credential and input source. This part builds an inventory that later parts use for identity, permissions, cost, review and audit decisions.
