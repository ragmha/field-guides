## What you will learn

Every automation run starts a cloud agent session that uses AI credits and GitHub Actions minutes. Nobody reviews each run's cost as it starts, so ceilings must be set in advance. This part assigns the bill, explains how per-run and periodic credit limits behave, and reduces how often runs start. It also covers the documented API rate limits that apply to scripts calling these endpoints.
