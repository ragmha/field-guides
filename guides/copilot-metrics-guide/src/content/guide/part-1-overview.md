## What you will learn

Copilot usage data reaches you through several surfaces: the usage metrics, code generation and impact dashboards, the usage metrics REST endpoints, and NDJSON exports. Each surface has a different scope, window and audience. This part maps those surfaces and explains how a policy, an enterprise or organization role, and a token scope decide who can read them.

By the end of the part you should be able to say which surface answers a given question and which people need access to it.
