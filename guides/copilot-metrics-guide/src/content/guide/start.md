This independent course is for enterprise and organization administrators, platform teams and engineering leaders who report on GitHub Copilot adoption. It covers where usage metrics come from, what each count means, why totals disagree across scopes, how latency and coverage limit what you can say, and how to design adoption KPIs that inform decisions without becoming individual surveillance. Each part explains one measurement decision, illustrates it with hypothetical examples, and ends with practice you can run in an authorized sandbox.

Each part's summary has a scored quiz. Answer every question correctly to unlock the next part; you can retry without penalty. Progress is stored in this browser, not in an account. JavaScript and browser storage are required for progression. The quiz is a learning aid, not a certification or tamper-proof assessment.

The examples do not change production settings. Confirm current documentation, your plan, permissions and your organization's approval process before acting. Advice is labeled as such; product behavior is linked to GitHub's sources.

For a broader introduction to Copilot governance, see the [Copilot governance overview course](/field-guides/copilot-governance-guide/). Credit budgeting is covered elsewhere and is not repeated here. See the [sources and status register](/sources/) for the documentation this course relies on and for items in public preview.
