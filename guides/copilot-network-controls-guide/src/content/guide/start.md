This independent course is for network, security and platform administrators who make GitHub Copilot work through corporate firewalls, proxies and inspection tools, and who decide what Copilot's cloud agent may reach. It separates three paths that are often confused: developer clients reaching Copilot, browsers streaming cloud sessions, and the agent's own environment reaching the internet. Each part explains one control, applies it to a hypothetical team and ends with a short practice task.

Each part's summary has a scored quiz. Answer every question correctly to unlock the next part; you can retry without penalty. Progress is stored in this browser, not in an account. JavaScript and browser storage are required for progression. The quiz is a learning aid, not a certification or tamper-proof assessment.

The examples do not change production settings. Confirm current documentation, your plan, permissions and your organization's approval process before acting. Advice is labeled as such; product behavior is linked to GitHub's sources.

For a broader introduction to access, policy, billing and agent governance, start with the [Copilot governance overview course](/field-guides/copilot-governance-guide/).
