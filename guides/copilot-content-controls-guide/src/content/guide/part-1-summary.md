## Key Takeaways

- An exclusion removes inline suggestions in the file, stops the file informing suggestions and responses, and skips it in Copilot code review.
- It does not change who can read or edit the file.
- Repository rules reach anyone in the enterprise working in that repository; organization rules reach users with that organization's seat; enterprise rules reach every Copilot user in the enterprise.
- Inherited rules appear read-only on the repository settings page.
