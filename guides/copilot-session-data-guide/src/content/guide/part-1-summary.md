## Key Takeaways

- Session data covers prompts, responses, tools used and file changes; session history is the set you can query.
- Where a session runs does not decide where its record lives, whether it syncs or who can see it.
- Cloud sessions on GitHub Actions and in cloud sandboxes have different defaults for persistence and sharing.
