## Key Takeaways

- Cloud agent sessions on GitHub Actions are shared by default; local and cloud sandbox sessions are not.
- Sharing grants view-only access to people with repository access and does not add to their query history.
- `/share file`, `/share html` and chat exports create copies outside GitHub's sharing and deletion controls.
