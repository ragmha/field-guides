## Key Takeaways

- Archive and hide change what you see; delete removes the record from the place where you run it.
- Cloud agent sessions can be archived but not deleted; local bulk cleanup never reaches synced copies.
- Documented retention windows differ by record type; where none is documented, data stays until deleted.
