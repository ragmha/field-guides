Use agent mode in VS Code to carry out a bounded, multi-file task while you supervise. Unlike a simple question, an agent can select files, propose edits, and use tools iteratively.

## What you will do

Prepare a task, select Agent in chat, assess tool requests, steer an iteration, and inspect and test the resulting changes. Interface labels, tool behavior, and automatic approvals depend on the client and its settings.

## Before you begin

Use a trusted, non-sensitive practice workspace and a signed-in account with Copilot access. Know your starting changes and project test command. The [IDE setup lessons](/field-guides/copilot-ide-guide/) cover installation; this track focuses on agent work.

## Completion check

You understand every kept change and can point to the actual verification result, not just the agent's summary.
