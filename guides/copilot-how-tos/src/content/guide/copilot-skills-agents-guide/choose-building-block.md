## Steps

1. Identify the repeated work. For a consistent release-note check, a skill can package the procedure and supporting material.
2. For a dedicated documentation reviewer with a specific role and tool set, consider a custom agent profile.
3. For a simple repository convention that should apply generally, use repository instructions instead of creating either building block.
4. Check the target client's current support and invocation behavior before choosing a format.

## Verify

A skill describes when and how to perform a workflow; an agent profile describes an agent's role and capabilities. Both need human review and a concrete task to be useful.
