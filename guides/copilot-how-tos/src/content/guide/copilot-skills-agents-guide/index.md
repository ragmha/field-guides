A skill packages instructions for a reusable workflow; a custom agent defines a specialized role and its available tools. This guide builds one small example of each in an authorized practice repository.

## What you will do

Choose the right building block, write and exercise a `SKILL.md`, then define and evaluate a focused agent profile. Client support, discovery, and tool names vary; use the current documentation for your surface.

## Before you begin

Use a trusted project with no credentials or sensitive data. Review any downloaded skill, script, or agent profile before using it. Neither instructions nor a tool list guarantees a safe or correct result.

## Completion check

You can explain when each building block is useful, inspect its contents, and verify its output on a small task.
