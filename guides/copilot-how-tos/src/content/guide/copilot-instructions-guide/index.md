Repository instructions give Copilot recurring project context without repeating it in every request. This guide creates concise, testable guidance in a fictional project and checks its effect.

## What you will do

Choose stable instructions, create the repository-wide file, add a path-specific rule, test representative requests, and maintain the files as the project changes.

## Before you begin

Use an authorized practice repository and a supported Copilot client. Support for instruction formats and precedence varies by surface; consult the current documentation for yours. Instructions are guidance, not a security control or a substitute for review.

## Completion check

The instructions are accurate, scoped, reviewed in the diff, and useful on a representative task without containing secrets.
