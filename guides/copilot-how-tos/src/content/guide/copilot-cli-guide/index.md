Work through a small change in a fictional reading-list utility using an interactive Copilot CLI session. You retain responsibility for the workspace, each permission decision, and the final result.

## What you will do

Prepare a trusted directory, describe a bounded task, evaluate tool requests, steer the session, and independently inspect and test the resulting changes. The walkthrough assumes a current Copilot CLI installation and an account with access; availability and prompts vary by version and policy.

## Before you begin

Use a project you may share with the service, without credentials or sensitive data. Know its existing changes and test command. Do not start in a directory whose files or instructions you do not trust.

## Completion check

You can explain what changed, which checks actually ran, and which actions you approved. A completion message is not proof of correctness.
