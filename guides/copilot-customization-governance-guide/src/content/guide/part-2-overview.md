## What you will learn

Customizations change agent behavior for everyone who reads them, so each one needs a named owner and a review path. This part separates ownership by scope: repository maintainers, organization owners and enterprise owners or delegated AI managers.

The first lesson builds an ownership model, including the enterprise option to protect agent files with rulesets. The second lesson follows a change from branch to pull request to default branch, with attention to when a change becomes active and which branch each experience reads.
