## What you will learn

You cannot govern what you have not found. This part maps the customization estate: custom instructions at personal, repository and organization scope, prompt files, custom agents, agent skills and plugins. You will learn where each type is stored, who can create it, and which surfaces actually read it.

The second lesson turns that map into a support check, because a file that one client honors may be ignored or only in public preview on another. Governance decisions that assume uniform support across GitHub.com, the CLI and IDEs tend to fail quietly.

By the end of this part you should be able to produce an inventory that names each customization, its storage location, its scope and the surfaces where it is expected to take effect.
