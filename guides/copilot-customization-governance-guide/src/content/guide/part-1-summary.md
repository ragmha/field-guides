## Key Takeaways

- Customizations exist at personal, repository, organization and enterprise scope, and each type has documented storage locations in the [customization cheat sheet](https://docs.github.com/en/copilot/reference/customization-cheat-sheet).
- Repository instructions include repository-wide, path-specific and agent instruction files; organization instructions are a setting that reaches only supported GitHub website experiences and code review.
- Support differs by surface. Check the [custom instructions support matrix](https://docs.github.com/en/copilot/reference/custom-instructions-support) and flag public preview cells.
- Guide advice: an inventory row should record path, scope, intended audience and supported surfaces before any ownership or retirement decision.

## Questions to discuss

- Which customization types in your estate have no known owner today?
- Which teams rely on a surface where support is public preview?
