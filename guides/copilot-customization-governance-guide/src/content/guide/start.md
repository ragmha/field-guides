This independent course is for platform engineers, developer-experience teams, repository maintainers and Copilot administrators who are responsible for the instructions, prompt files, custom agents, agent skills and plugins that shape how Copilot behaves. It treats those files as shared agent infrastructure: something with owners, review, versions, distribution channels and an end of life. Each part pairs documented product behavior with hypothetical examples and a sandbox exercise.

Each part's summary has a scored quiz. Answer every question correctly to unlock the next part; you can retry without penalty. Progress is stored in this browser, not in an account. JavaScript and browser storage are required for progression. The quiz is a learning aid, not a certification or tamper-proof assessment.

The examples and practice steps do not change production settings or shared repositories. Use an authorized sandbox organization or repository, confirm current documentation, your plan and your permissions, and follow your organization's approval process before acting. Advice is labeled as such; product behavior is linked to GitHub and Visual Studio Code documentation.

The course covers customization files and their lifecycle. Policies, managed settings, MCP allowlists, network controls, audit telemetry and metrics are covered by sibling courses and are only mentioned here where a customization decision depends on them. See the [sources and release status register](/sources/) for review dates and public preview boundaries.
