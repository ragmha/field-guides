## What you will learn

Rules let routine commands run without a prompt while risky ones still stop for a person. Learn how Copilot CLI combines tool, path and URL rules, and how VS Code matches terminal auto-approval rules. Both are best-effort matching, so the lessons pair rules with sandboxing rather than replacing it.
