This independent course is for platform engineers, security reviewers and developer-experience leads who decide how agentic Copilot clients, such as Copilot CLI and agent sessions in Visual Studio Code, run on developer machines. It covers trusted directories, permission modes, command auto-approval, local sandboxing, credential exposure and stronger isolation. Each part pairs a decision with hypothetical examples and a hands-on practice task. For the wider governance picture, see the [Copilot governance course](/field-guides/copilot-governance-guide/).

Each part's summary has a scored quiz. Answer every question correctly to unlock the next part; you can retry without penalty. Progress is stored in this browser, not in an account. JavaScript and browser storage are required for progression. The quiz is a learning aid, not a certification or tamper-proof assessment.

The examples do not change production machines, settings or credentials. Practice on a disposable or approved test environment, and confirm current documentation, your plan, platform support and your organization's approval process before acting. Advice is labeled as such; product behavior is linked to the GitHub and Visual Studio Code sources.

Enterprise-wide enforcement through managed settings, MCP server governance, cloud agent security and organization network controls are covered by sibling courses and are only referenced here. See the [sources and status register](/sources/) for review boundaries and preview features.
