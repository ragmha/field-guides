## What you will learn

The earlier parts described each layer. This part makes the map operational. You will build an inventory with a consistent set of fields, link each control to the risks it reduces, and look for risks without a control and controls without an owner. Then you will use a short decision sequence to choose the right layer for a new requirement, using GitHub's [governance controls overview](https://docs.github.com/en/copilot/concepts/enterprise/governance-controls) and its [adoption guidance](https://docs.github.com/en/copilot/tutorials/roll-out-at-scale/govern-at-scale/govern-for-adoption) to avoid over-restricting.

- Define inventory fields and a review cadence.
- Build a risk-to-control matrix and read gaps from it.
- Choose a layer by reach, enforcement strength and evidence.
