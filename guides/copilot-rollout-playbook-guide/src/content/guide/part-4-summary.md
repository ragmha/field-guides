## Key Takeaways

- GitHub's example timeline runs from preparation about 45 days out to launch-day support and on-demand training.
- Resolve proxy and firewall questions in preparation; name an internal contact before escalating to GitHub Support.
- Use the built-in request flow with a review cadence, or an API flow with automated checks.
- Publish expectations, such as an inactivity policy, with the launch.
