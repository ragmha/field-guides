## Key Takeaways

- Confirm licenses, set policies, enable one organization, then set a budget.
- Keep default availability on; disable only non-negotiables and scope restrictions to sensitive organizations.
- Rely on rulesets, required checks and security scanning as guardrails for all code.
- Treat exceptions as scoped, expiring grants; confirm changes with `action:copilot` within the 180-day audit log window.
