This independent course is for enterprise and organization owners, security operations analysts, incident responders and platform engineers who need evidence about GitHub Copilot. It covers where Copilot audit events appear, which fields agent records carry, how long each source keeps data, how to stream it, and how to build investigation playbooks and alerts that respect what each record can and cannot prove.

Each part's summary has a scored quiz. Answer every question correctly to unlock the next part; you can retry without penalty. Progress is stored in this browser, not in an account. JavaScript and browser storage are required for progression. The quiz is a learning aid, not a certification or tamper-proof assessment.

The examples do not change production settings. Confirm current documentation, your plan, permissions and your organization's approval process before acting. Advice is labeled as such; product behavior is linked to GitHub's sources. Several capabilities covered here are in public preview, and the [sources and status register](/sources/) lists them.

For the wider governance picture, including access, policies and cost, see the [Copilot governance course](/field-guides/copilot-governance-guide/). Usage metrics dashboards and the handling of session content are covered by separate courses; this one stays with audit evidence and the telemetry used to corroborate it.
