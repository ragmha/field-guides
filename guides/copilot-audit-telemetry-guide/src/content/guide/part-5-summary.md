## Key Takeaways

- Run investigations in five stages: scope, triage, collect, attribute, conclude.
- Record exact queries so others can repeat them and see coverage.
- Bounded findings state what the evidence shows, what it does not, and which sources were unavailable.
- Alert rules need an owner, a condition and a response; deduplicate before counting.
- Monitor the stream itself so silence is not mistaken for safety.
