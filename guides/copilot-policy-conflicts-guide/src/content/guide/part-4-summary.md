## Key Takeaways

- Most policies follow the licensed user; a few govern a setting for everyone, and the policy description highlights them.
- Repository-level content exclusion affects any Copilot user in the enterprise working in that repository.
- Organization owners can block Copilot in the cloud for some or all repositories.
- Check the supported surfaces reference before treating a result as a conflict.
- Cloud sandbox and GitHub Actions coverage can differ.
