## What you will learn

- Find the key platform, privacy and migration terms used in the course.

| Term | Meaning |
| --- | --- |
| Controller | The party determining the purposes and means of processing personal data. |
| Data residency | A commitment concerning the region where applicable data is stored or processed. |
| DPA | Data protection agreement setting out processor and related privacy terms. |
| DPIA | Data protection impact assessment, used to assess high-risk processing where required. |
| EMU | Enterprise Managed User, an account provisioned and controlled through an organisation's identity provider. |
| GEI | GitHub Enterprise Importer, a migration tool; supported sources and migrated data vary. |
| GHE.com | GitHub Enterprise Cloud with data residency, using an enterprise-specific subdomain and selected region. |
| IdP | Identity provider, used to authenticate and provision managed accounts. |
| Processor | A party processing personal data on behalf of a controller. |
| SCIM | System for Cross-domain Identity Management, used here to provision managed users. |
| SCCs | Standard Contractual Clauses, a contractual mechanism for qualifying international transfers. |
| TIA | Transfer impact assessment, an assessment of relevant transfer risks and safeguards. |
