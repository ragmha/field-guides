This independent course is for enterprise and organization administrators, security and privacy reviewers, and platform owners who decide which AI models GitHub Copilot users can select. It covers release status, availability policies, provider hosting and data terms, automatic model routing, cost signals, bring your own key (BYOK) and a repeatable review process. Each part pairs a decision with hypothetical examples and a practice task.

Each part's summary has a scored quiz. Answer every question correctly to unlock the next part; you can retry without penalty. Progress is stored in this browser, not in an account. JavaScript and browser storage are required for progression. The quiz is a learning aid, not a certification or tamper-proof assessment.

The examples do not change production settings. Confirm current documentation, your plan, permissions and your organization's approval process before acting. Advice is labeled as such; product behavior is linked to GitHub's sources.

Model lists, prices and release phases change often, so this course describes model categories rather than naming specific model versions. Check the [supported models reference](https://docs.github.com/en/copilot/reference/ai-models/supported-models) for current names. See the [sources and status register](/sources/) for review dates and preview boundaries.
