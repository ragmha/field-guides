## Key Takeaways

- Auto and Fusion choose only from models the user can already reach.
- Auto tiers change preference, not eligibility; usage is billed at the selected model's rate.
- Business and Enterprise Auto falls back to the long-term support model if nothing else is available.
- Fusion bills each model it uses; disabling required models can hide Fusion Max.
- Fusion local model routing is a public preview.
