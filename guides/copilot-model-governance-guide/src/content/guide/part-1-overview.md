## What you will learn

Learn what determines whether a model appears for a user and how release stages signal readiness. A governance decision starts with an inventory: which model categories exist, which surfaces offer them, and which are still in preview or evaluation. The [models overview](https://docs.github.com/en/copilot/concepts/models/overview) explains that plan, surface, policies and time all affect availability.
