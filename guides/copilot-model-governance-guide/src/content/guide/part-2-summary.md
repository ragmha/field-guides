## Key Takeaways

- Explicit Enabled and Disabled states survive changes to the default availability policy.
- Preview, open-weight and non-retention-covered models are not enabled by the default.
- Default availability is unrelated to the default model in a session.
- Targeted access rules scope a model to selected organizations.
- Enterprise teams mode is a public preview that deactivates organization model settings.
