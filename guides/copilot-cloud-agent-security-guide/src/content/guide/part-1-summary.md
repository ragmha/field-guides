## Key Takeaways

- The Copilot in the cloud policy is enabled by default and covers cloud sandboxes; organizations cannot override an enterprise choice.
- Organization repository access and repository opt-outs narrow where the agent can work.
- Only users with write access can trigger the agent, and other users' comments are never presented to it.
